# XWXTodo 功能

XWXTodo = macOS 本地 TODO App。顶部黑色刘海屏提示当前事项；悬停展开 TODO 面板。

## 能力

- 刘海屏：doing TODO -> 标题；无 doing -> 剩余待办数；全完成 -> 完成提示。
- 悬停刘海屏 -> 展开 TODO 面板；鼠标离开 -> 收回。
- TODO：新增、编辑、删除、开始、暂停、完成。
- 状态：同一时间最多一个 doing。
- 列表：主列表只显示未完成；已完成列表单独查看。
- 主窗口：登录、自动恢复登录、连接异常重试、同步失败提示、退出登录。
- 同步：登录后 TODO 读写走云端；App 运行中持续同步；未登录或启动同步失败时不展示旧 TODO。
