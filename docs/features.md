# XWXTodo Features

XWXTodo 是一款 macOS 本地 TODO 应用。它通过屏幕顶部的黑色刘海屏提醒用户当前正在处理的事项，并在悬停后展开为 TODO 管理弹窗。

## 核心能力

- 顶部刘海屏常驻显示当前正在做的 TODO。
- 悬停刘海屏平滑展开 TODO 管理弹窗，鼠标离开后平滑收回。
- 支持新增、编辑、删除、开始和完成 TODO。
- 同一时间只允许一个 TODO 处于正在做状态。
- 主列表只显示未完成 TODO。
- 已完成 TODO 可在已完成列表中查看。
- TODO 数据保存在本机。
