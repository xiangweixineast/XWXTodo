# Triage Labels

工程技能使用五个标准 triage 角色。本文件记录这些角色在本仓库中的状态字符串。

| Skill role | Tracker label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，适合 AFK agent 接手 |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不处理 |

当技能提到某个 triage role 时，使用上表对应的 `Tracker label`。
